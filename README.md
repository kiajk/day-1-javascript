تفاوت find، map و filter در JavaScript

find برای پیدا کردن اولین آیتمی استفاده می‌شود که شرط موردنظر ما را داشته باشد و خروجی آن یک آیتم است. اگر چیزی پیدا نشود، مقدار undefined برمی‌گرداند.

filter برای پیدا کردن تمام آیتم‌هایی استفاده می‌شود که شرط موردنظر ما را داشته باشند و خروجی آن یک آرایه جدید است.

map برای تغییر یا تبدیل تمام آیتم‌های یک آرایه استفاده می‌شود و خروجی آن یک آرایه جدید است.

به طور خلاصه:

find → یک مورد را پیدا می‌کند.

filter → چند مورد را بر اساس شرط جدا می‌کند.

map → تمام آیتم‌ها را تغییر یا تبدیل می‌کند.
